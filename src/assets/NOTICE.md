# このディレクトリの素材について

`musmus-starry-eyed.mp3` は、フリーBGM・音楽素材 **MusMus**（作曲: watson）の
**Starry Eyed / YM-2608 Chiptune** を、MusMus の[利用規約](https://musmus.main.jp/info.html)に従って
**このゲームの BGM として**同梱しているもの。

## 素材として使いたい方へ

このファイルを取り出して別の作品に使わないこと。MusMus の規約は
「MusMus にアクセスせずに楽曲を素材として使用できる状態」を 2 次配布として禁じている。

音楽素材を使いたい場合は、**MusMus から直接ダウンロードしてください**。

- 配布元: https://musmus.main.jp/
- この曲のページ: https://musmus.main.jp/chiptune.html
