# SEA STRIKE

海上を飛行する一人称視点の 3D シューティング。スマホを**傾けて**照準し、発射ボタンで敵戦闘機を撃つ。

**▶ https://bubbleshaker.github.io/sea-strike/**

## 操作

| | 傾け操作 | 代替操作 |
|---|---|---|
| 照準 | 端末を傾ける | 画面をスワイプ |
| 発射 | 発射ボタンをタップ | 同左 |
| 武器切替 | 武器アイコンをタップ | 同左 |

傾きセンサーが使えない端末・PC でも、スワイプで同等に遊べる。
iOS では安全上、傾きセンサーの利用に本人の許可が要るため、開始前に確認が出る。

BGM は画面右上の `♪` で切り替えられる（設定は次回も引き継ぐ）。
音はブラウザの制限で、開始画面のボタンを押した後から鳴り出す。

## 勝敗とスコア

規定数の敵機を撃墜すれば勝ち。被弾で HP が尽きれば負け。
スコアは撃墜数に加えて、**クリアタイム**と**被ダメージ**を織り込む。速く、傷を負わずに落とすほど高い。
